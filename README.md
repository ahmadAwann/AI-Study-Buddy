# AI Study Buddy — Short Project Description

# AI Study Buddy is a Flutter mobile application that helps students study efficiently by using AI to generate short notes, summaries, and five multiple-choice questions (MCQs) from any given topic.

# Main Features:

# \- AI Integration: Generate notes, summaries, and quizzes from a topic.

# \- Hive Database: Save notes, quiz results, and study history locally for offline access.

# \- Stripe Payments: Allow users to purchase a premium study pack with additional AI-generated content.

# \- User Interface: Simple screens for entering topics, viewing notes, taking quizzes, and accessing saved material.

# Technologies: Flutter, Dart, Hive, AI API, and Stripe.

# Objective: To provide students with a simple, AI-powered study assistant that makes learning and revision faster and more convenient.
